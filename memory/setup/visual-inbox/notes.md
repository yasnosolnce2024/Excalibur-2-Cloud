Дата: 2026-08-14.  
Файлов-картинок нет (фото Елены не присылали и не использовать).

## cover_mode

`illustrative` — человека-героя с реальным лицом **нет**.  
Не `host_reference`. Не генерировать «портрет Елены».

## Размеры

- VK обложка / квадрат: **1:1**
- Дзен карточка и quad-панель пайплайна: **16:9**
- Quad canvas по контракту: 2048×1152 (2×2), каждая панель 16:9; для VK — отдельный квадратный кроп/экспорт из cover, не чужое лицо

## Настроение

Тёплая кухня. Жизнь. Достоинство. Утренний свет в окне, стол, лён, чай, хлеб, руки с едой (без идентифицируемого лица), пар, дерево, мёд, шалфей.

Leitmotif: возраст — паспорт, не приговор. Обложка не стыдит морщины и не продаёт «омоложение».

Рубрика «Формула вкуса»: кухня с нуля, детская мечта готовить — метафоры еды и стола уместны.

## Цвета (предложение Setup, не чужой pink-cat бренд)

- Фон панелей по контракту пайплайна: чистый белый `#FFFFFF` (не beige full-bleed)
- Чернила: тёплый почти-чёрный `#2A2118` / запасной контрактный `#141821`
- Акцент: терракота / мёд `#C45C26`, шалфей `#6B8F71`, дерево `#8B5E3C`
- Не использовать дефолтный `#FF1493` / кошачий коллаж / белое худи ведущего

## Надписи

Русский, тёплый, короткий hook. `meme_caption_ru` пуст. Без «EXCALIBUR», без мемов Drake/facepalm.

## Запреты

- Реальные фото Елены (их нет)
- Anti-age стыд, «до/после», разглаживание возраста как дефекта
- Чужое лицо, худи, pink-cat бренд-коллаж
- Сток-баннер «счастливая пенсионерка»
- Ключ Kie не выдумывать
