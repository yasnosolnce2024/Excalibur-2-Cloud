# Вопросы, на которые может ответить только Елена

Setup остановился здесь. Не выдумывать пароли, URL сайта, ключи и фото.

1. **URL живого сайта (WordPress)** для Cloud Secret `PUBLIC_SITE_URL`. В git остаётся только `{{SITE_BASE}}`. Если сайта ещё нет — так и напишите.
2. **SFTP для публикации:** есть ли хост / пользователь / корень (`FTP_HOST`, `FTP_USER`, `FTP_PASS`, `FTP_ROOT`)? Значения — только в Cloud Secrets, не в чат-файл и не в git.
3. **Референсы обложек:** 2–6 картинок настроения (кухня, свет, стол, руки с едой — без обязательного лица). Можно файлы или ссылки на свои обложки VK/Дзен. Фото Елены пока не нужны: режим `illustrative`.
4. Нужен ли **Wordstat** для Scout (MCP)? Если да — токен тоже в Secrets.
5. Есть ли **Telegram / MAX / отдельный сайт автора** для `sameAs` в карточке автора?
6. Когда появится **KIE_API_KEY** — положить в Cloud Secrets. Не писать ключ в репозиторий.

После ответов: дописать Secrets в Environment, прислать moodboard → повторный Setup Visual при необходимости → stamp `complete=true`.
